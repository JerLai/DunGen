## Update on stalled development progress (02/11/2025) (February 11th)
Another update snippet exists on the website. In short, I decided to restart development on this tool, potentially using a new language (or even still another Engine).
Previous development on the tool used Unity had its shortcomings, and the implementation after doing a retrospection on it, I was not happy with the quality. Coupled with
the [Unity fiasco](https://www.bloomberg.com/news/newsletters/2023-09-15/unity-technologies-rolls-out-new-fees-destroys-its-goodwill-with-developers) I thought it prudent
to leave the tool.

I wanted my tool to focus on the core idea, generating dungeon/map layouts where you could change the generation algorithm, the parameters to whatever you desire. I always
intended the tool to generate a file, a template of sorts that would be easily readable, or at the very least have a document specification so people using different engines
would be able to parse that file correctly to use the map defined in the template. Using Unity made some of the visualizations very nice and easy, but had some extra baggage to deal with.
Thus, I wanted to restart with a fresh mind after years in the same headspace, and see what kind of growth I have had to general the tool of my vision.
